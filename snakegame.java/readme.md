# 🐍 Console Snake Game (Java)

A simple Snake Game built using Java that runs in the console. Control the snake using keyboard inputs and try to eat as much food as possible without hitting the walls or yourself.

---

## 🚀 Features
- Console-based gameplay
- Simple grid system
- Snake movement using keyboard (W, A, S, D)
- Food spawning at random positions
- Score tracking
- Collision detection (wall & self)

---

## 🎮 Controls
| Key | Action |
|-----|--------|
| W   | Move Up |
| S   | Move Down |
| A   | Move Left |
| D   | Move Right |

---

## 🧠 Game Logic
- The snake starts at the center of the grid.
- Food (`X`) appears randomly.
- Each time the snake eats food:
  - Score increases
  - Snake grows longer
- Game ends when:
  - Snake hits the wall
  - Snake collides with itself
